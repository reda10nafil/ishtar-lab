# Contributi a Ishtar Lab

Le condizioni per gli eventuali destinatari sono in LICENSE.md e LICENSING-SCOPE.md. Il titolare è Reda Zahloul, nome pubblico del progetto Ishtar Hub; il recapito per restituire le modifiche è ralreda54@gmail.com. Non è aperto un repository pubblico di contributo.

Prima di modificare i Materiali Ishtar ottenere il permesso scritto di Reda Zahloul per il lavoro previsto. L’accesso al repository non sostituisce questo permesso. Per l’uso commerciale occorre inoltre un accordo scritto separato con il titolare.

Per restituire una modifica autorizzata, preparare:

1. Descrizione del problema, comportamento ottenuto e file toccati.
2. Sorgenti modificabili e patch, nuove dipendenze e relative licenze.
3. Istruzioni per riprodurre l'avvio e le verifiche; migrazioni prive di dati privati.
4. Nome del contributore, data e dichiarazione dei diritti sulle parti consegnate.
5. Accettazione espressa della concessione di ritorno prevista nella licenza, senza trasferire segreti o dati di clienti.

Non inviare .env, credenziali, database, volumi, log o il salvataggio storico. Inviare a ralreda54@gmail.com con oggetto «Ishtar Lab — restituzione modifiche», tramite archivio sorgente o collegamento riservato accessibile al titolare. Per file troppo grandi concordare un canale alternativo. Il recapito è stato comunicato dall'utente; nessuna email di prova, pubblicazione o invio automatico è stato eseguito.

Per sviluppare leggere AGENTS.md, PROJECT.md e .ai-style-rules.md. Conservare UI e componenti originali. Questa guida non modifica il regime MIT del sottoalbero backend/piattaforma né le licenze di terzi.
